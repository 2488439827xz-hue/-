### 1. NVIDIA/SkillSpector · 84.0/100
https://github.com/NVIDIA/SkillSpector

- **一句话**：NVIDIA 推出的 Agent Skills 安全扫描器，可检测 prompt 注入、数据外泄、供应链风险等 68 种漏洞模式，支持多种输入格式和输出报告，并集成 OSV.dev 实时 CVE 查询。
- **解决的问题**：AI Agent 技能在执行时拥有隐式信任，但缺少安全审查，26.1% 的技能存在漏洞，5.2% 有恶意行为迹象。用户需要工具在安装前评估风险。
- **独特之处**：作为官方工具，它被整合进 NVIDIA Verified Skills 流水线，具备厂商背书和持续更新，覆盖 17 类安全模式，提供双阶段分析（静态+可选 LLM），支持供应链漏洞实时查询。
- **为什么有价值**：安全是 Agent 技能大规模采用的关键障碍，此工具为个人和团队提供了实际防护手段，是了解 Agent 安全最佳实践的窗口。
- **与你的关系**：当下：使用它扫描你计划安装的任何技能，或学习其风险评分模型。未来：将安全扫描集成到自己的 Agent 工作流中，或参与贡献以深入安全领域。
- **建议动作**：阅读其扫描文档，对任意一个技能仓库运行扫描，并浏览报告中的风险评分与建议。
- **Star 原因假设**：NVIDIA 官方背书和验证流水线带来信任；；Agent 安全是刚需，新闻热点推动搜索；；首次快照数据，Star 可能包含初期积累。
- **风险/限制**：存在 89 个未关闭 issue，可能影响稳定性；；需要 Python 3.12+，环境要求较高；；LLM 语义分析可能引入额外成本或误报。
- **判断置信度**：高

## 今日重点

NVIDIA/SkillSpector: 目标用户是 Claude Code、Codex 等 Agent 的用户和企业安全团队。待办任务是在安装前扫描技能，识别恶意模式。旧替代方案是手动审查或凭经验相信来源。价值主张是机器可验证的安全、透明、可重复。AI 是否必要？是，静态分析难以捕捉语义漏洞，LLM 提供额外语义层。核心指标是检测到的漏洞数、误报率、扫描速度。主要风险是漏报（恶意技能绕过检测）和误报导致用户忽略警告。作品集衍生想法：构建一个“技能安全评分卡”SaaS，基于 SkillSpector 输出生成可分享报告，并添加合规建议，用于展示产品设计与安全结合能力。
