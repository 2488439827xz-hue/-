### 2. zhuyansen/agent-skills-hub · 78.5/100
https://github.com/zhuyansen/agent-skills-hub

- **一句话**：开源目录，对 117k+ Agent Skills 与 MCP Server 进行 10 维度评分与安全分级，每隔 8 小时更新，支持对比与场景化推荐，并提供 Web 界面。
- **解决的问题**：技能市场无质量信号，用户难以评估技能可信度与安全性，尤其缺乏统一标准。
- **独特之处**：将质量评分与安全分级引入技能目录，强调工程化与自动化，且基于持续抓取而非人工静态列表。
- **为什么有价值**：其评分体系为 PM 提供用户需求与质量评估的实例，且安全分级满足企业关怀。
- **与你的关系**：当下可用于评估技能质量，理解用户如何做决策；未来可用其方法论设计产品品质体系。
- **建议动作**：阅读其安全报告或评分方法论，对比 3 个同类技能，并记录质量信号。
- **Star 原因假设**：假设：随着技能安全性担忧，其权威评级填补空白；支持信号：README 强调 security-graded；假设：自动化更新保证新鲜度，受到用户信任；支持信号：8 小时刷新管线与 GitHub Actions；假设：提供 Web 产品与 /best/ 场景页面，降低使用门槛；支持信号：清晰的分类与比较功能
- **风险/限制**：缺少许可证文件，长期维护法律风险；评分算法可能偏颇，过度自动化缺乏人工审视；项目活跃度下降风险，目前用户量较低
- **判断置信度**：medium

### 3. ctxrs/ctx · 76.0/100
https://github.com/ctxrs/ctx

- **一句话**：开源 CLI 可搜索本地过去编码代理会话历史，并提供 ctx pro 付费版本来行级溯源（类似“Git blame for agent sessions”）。
- **解决的问题**：Agent 会话记录分散在日志，无法检索，导致重复工作与决策追踪困难。
- **独特之处**：提供会话历史的本地全文搜索与上下文恢复，并将付费能力（ctx pro）与开源版区分。
- **为什么有价值**：演示用户价值分层与商业化模式，是 PM 可以逆向重构的经典工具产品。
- **与你的关系**：当下可用于提升你对代码代理工作流的理解；未来可参考其模式思考产品付费墙。
- **建议动作**：安装 ctx，用你的历史代理日志执行一个搜索，观察结果如何还原会话上下文。
- **Star 原因假设**：假设：开发者受困于 Agent 记忆需求，接受该解决方案；支持信号：README 强调降低 token 成本；假设：ctx pro 付费功能引发讨论，但可能免费版就足以吸引用户；假设：github 上的 1062 星暗示技术验证充分，尤其 Rust 高性能实现带来口碑
- **风险/限制**：商业延伸可能引起社区反感，需关注可持续性；无安全信号，历史数据敏感；仅支持部分平台，可能影响覆盖面
- **判断置信度**：medium

## 今日重点

聚焦 zhuyansen/agent-skills-hub。目标用户：开发者、企业架构师与 AI 产品经理，他们需要选择可信的 Agent 技能与 MCP Server。待办任务：在 30 秒内找到满足任务的技能，并判断其质量与安全性。旧替代方案：手动搜索 random GitHub topics（如 awesome lists），耗时且缺乏质量信号。价值主张：提供 117k+ 项目的自动更新目录，附带 10 维度评分与安全分级，实现快速且可信的对比选择。AI 是否必要：是，海量项目与频繁更新需要自动化筛选与评分，人工无法持续。核心指标：找到合适技能的时长；项目被选中的比率；安全报告阅读量；用户留存。主要风险：评分算法的偏差与主观；自动更新可能因 API 变动失效；能否实现商业可持续尚不明朗。作品集衍生想法：以一个假想需求（如搭建合同审查 Agent）为例，基于该目录进行选型对比，输出一份 1 页选型评估报告，并分析其质量评分如何影响最终决策。
