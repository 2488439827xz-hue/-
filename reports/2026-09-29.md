### 1. supabase/agent-skills · 73.0/100
https://github.com/supabase/agent-skills

- **一句话**：Supabase 官方出品的 Agent Skills 集合，把 Supabase 与 Postgres 的开发经验封装为可被多种 AI agent 发现和调用的 SKILL.md 指令包，支持 npx 与 Claude Code 插件两种安装方式。
- **解决的问题**：AI coding agent 在使用 Supabase/Postgres 时容易给出过时或非最佳实践的写法，缺乏权威、可版本化的领域知识注入手段。
- **独特之处**：由数据库平台官方维护，把‘平台最佳实践’变成可安装的 skill，而不是靠用户反复在对话里纠正；给出了插件与 skill 双通道分发方式。
- **为什么有价值**：它示范了‘厂商把产品知识封装为 agent skill’这一新分发形态，是观察 skill 商业价值与生态位的好样本。
- **与你的关系**：当下：读懂一个成熟 SKILL.md 的信息结构与触发条件，理解 agent 如何选择 skill。未来：把这种‘领域最佳实践→skill’的模式迁移到你负责的产品，让 agent 成为产品的新分发入口。
- **建议动作**：用 `npx skills add supabase/agent-skills` 安装到本地 agent，打开生成的 SKILL.md 文件，记录其目录结构、触发描述写法与示例组织方式。
- **Star 原因假设**：假设：Supabase 开发者基数大，官方背书的 skill 安装量被转化为 Star 关注。支持信号：仓库由 supabase 组织拥有，文档指向官方 docs；假设：Agent Skills 标准早期红利，官方目录被 agent 生态工具（skills.sh 等）收录带来曝光。支持信号：readme 声明兼容 18+ agent
- **风险/限制**：open_issues 数量高（503），可能存在文档或 issue 维护滞后的体验问题；skill 实际效果依赖具体 agent 运行时，README 未给出统一评测结果；证据仅来自 README 摘要，未验证 skill 内容质量
- **判断置信度**：medium

### 2. alibaba/skill-up · 68.5/100
https://github.com/alibaba/skill-up

- **独特之处**：不做 skill 集合，而做 skill 的评测与进化，切入生态里被忽视的质量环节。
- **为什么有价值**：对产品经理而言，‘如何定义 skill 好坏’比‘收集更多 skill’更接近可复用的方法论，可支撑评测指标体系设计。
- **与你的关系**：当下：用它的思路设计一组 skill 评测维度（成功率、步骤数、回退行为）。未来：把 skill 评测纳入你产品的 prompt/agent 迭代流程。
- **建议动作**：阅读仓库文档主页（alibaba.github.io/skill-up）并写下 3 个你认为最该被评测的 skill 质量维度，形成一页笔记。
- **Star 原因假设**：假设：阿里品牌与 Agent Skills 热度叠加带来初始关注。支持信号：stars 1110，近期 star_delta 74/6 天；假设：skill 评测是生态空白，开发者对‘怎么评估 skill’有真实搜索需求。支持信号：同类项目多为集合型而非评测型
- **风险/限制**：README 摘录为空，安装、示例、文档无法从证据确认，实用性存疑；评测标准是否公开、是否可复现无法验证；项目较新，成熟度不确定
- **判断置信度**：low

## 今日重点

supabase/agent-skills 拆解：目标用户是使用 AI coding agent 的 Supabase/Postgres 开发者。待办任务是让 agent 写出符合官方最佳实践的数据库与认证代码，而非靠用户逐句纠错。旧替代方案是查文档、翻博客、在对话里粘贴规范片段。价值主张是把官方领域知识版本化为可安装、可发现的 SKILL.md，通过 npx 与 Claude Code 插件双通道分发。AI 是否必要：是——skill 的价值正是让非确定性 agent 在特定领域稳定复现专家做法，纯文档无法实现自动触发。核心指标可设为：安装量、触发命中率、生成 SQL 的一次通过率、RLS 相关错误率。主要风险：503 个 open issues 暗示维护压力，skill 效果缺少统一评测，且依赖具体 agent 运行时。作品集衍生想法：做一个‘把某产品最佳实践转为 SKILL.md’的端到端小案例，包含触发条件、示例、边界与一次简单评测结果，展示你理解 agent 分发新形态。
