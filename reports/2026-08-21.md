## 今日项目

### 1. NVIDIA/SkillSpector · 87.5/100
https://github.com/NVIDIA/SkillSpector

- **一句话**：NVIDIA 开源的 Agent Skills 安全扫描器，可检测提示注入、数据外泄、供应链风险等漏洞，支持多种格式输入和 LLM 语义分析。
- **解决的问题**：Agent Skills 常被隐式信任，导致恶意技能可能窃取数据或破坏系统。
- **独特之处**：首个由大厂发布的专业 Agent Skills 安全扫描器，结合静态分析与 LLM 评估，提供 70+ 漏洞模式。
- **为什么有价值**：它让开发者能在安装前评估技能风险，弥补生态中的关键安全缺口。
- **与你的关系**：当下可扫描依赖的 skills，确保安全；未来可作为产品安全模块的参考架构。
- **建议动作**：尝试扫描一个开源 skill 仓库，生成 JSON 报告并查看风险评分。
- **Star 原因假设**：NVIDIA 品牌背书吸引关注；安全话题在 agent 生态中备受重视；近期 AI 技能安全事件推动需求
- **风险/限制**：静态分析可能有误报，需要人工复核；项目依赖持续更新以应对新漏洞
- **判断置信度**：高

### 3. ctxrs/ctx · 79.5/100
https://github.com/ctxrs/ctx

- **一句话**：用 Rust 编写的 CLI 工具，可搜索历史 agent 会话记录，支持跨会话检索，提高 agent 工作连续性。
- **解决的问题**：编码 agent 的会话历史被隔离，导致重复劳动和上下文丢失。
- **独特之处**：提供类似 git blame 的 agent 会话搜索，让 agent 能找回先前决策。
- **为什么有价值**：直接解决 agent 记忆不足的问题，提升生产力，具有独特价值。
- **与你的关系**：当下可安装并搜索自己的历史会话，找回设计决策；未来可集成到工作流。
- **建议动作**：安装 ctx，运行一个简单查询，查看它如何处理会话索引。
- **Star 原因假设**：开发者渴望减少重复的 agent 工作；首个针对 agent 会话历史检索的工具；Rust 性能和安全吸引关注
- **风险/限制**：目前仅支持本地索引，跨设备同步未实现；商业版可能限制功能，影响社区使用
- **判断置信度**：中高

## 今日重点

NVIDIA/SkillSpector：面向 AI agent 技能生态的安全扫描器。目标用户是使用 Claude Code、Codex 等工具的开发者，待办任务是在安装新技能前扫描其仓库，检测潜在安全风险。旧替代方案是手动审查代码或信任来源，效率低且不可靠。价值主张是提供快速、自动化的风险评分，帮助用户做出安全决策。AI 的必要性在于其静态分析无法覆盖所有威胁，LLM 语义分析能识别模糊的恶意模式。核心指标是检测的漏洞数量和误报率。主要风险是误报可能导致用户忽略真实威胁，以及依赖 LLM 可能引入新成本。作品集衍生想法：构建一个团队内部的技能安全评估报告，展示你如何应用该工具并改进流程。
