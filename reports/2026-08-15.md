### 2. NVIDIA/SkillSpector · 79.5/100
https://github.com/NVIDIA/SkillSpector

- **一句话**：SkillSpector 是 NVIDIA 开源的 Agent Skills 安全扫描器，可检测提示注入、数据外泄、供应链风险等 69 种漏洞模式，支持多格式输入与多种输出。它基于 26.1% 的技能存在漏洞的研究，提供风险评分与基线抑制功能。
- **解决的问题**：用户在安装 Claude Code、Codex 等 Agent Skills 时缺乏安全验证手段，恶意或漏洞技能可能被直接执行，导致数据泄露或系统损害。
- **独特之处**：专为 Agent Skills 设计的安全扫描器，覆盖 17 类 69 种漏洞模式，结合静态分析与可选 LLM 语义评估，并提供实时的 CVE 查询，是当前少数聚焦技能供应链安全的工具。
- **为什么有价值**：Agent Skills 正在爆发式增长，安全是采用的瓶颈；SkillSpector 提供可操作的验证手段，帮助用户和团队安全使用技能，同时也展现 NVIDIA 在 Agent 治理上的布局。
- **与你的关系**：当下可用它扫描你计划安装的技能，避免引入风险；未来可研究其检测规则设计，理解 Agent 安全边界，为产品安全设计提供参考。
- **建议动作**：安装并试用 SkillSpector，扫描一个你常用的 Agent Skill 仓库，阅读报告并记录关键风险类型。
- **Star 原因假设**：NVIDIA 品牌背书和官方发布带来初始关注；安全问题在 Agent 社区中普遍存在，解决真实痛点；高星星增长可能因媒体报道和社区分享推动
- **风险/限制**：项目较新（2026-03 创建），可能缺少长期稳定性验证；无测试指标，可能影响可靠性；LLM 语义评估需要额外调用，可能增加使用成本
- **判断置信度**：高

### 3. ctxrs/ctx · 76.5/100
https://github.com/ctxrs/ctx

- **一句话**：ctx 是一个 Rust 编写的 CLI，用于本地快速搜索历史编码代理会话，类似 agent 会话的 git blame。它结构化索引代理历史，减少重复探索，token 效率相比原始搜索提升 50 倍。
- **解决的问题**：编码代理每次从零开始，无法利用过去的决策、失败尝试和命令，导致重复工作和效率低下。
- **独特之处**：提供本地私有的代理会话历史搜索，结构化索引会话和事件，极大提升 token 效率，且支持多种代理工具，是 Agent 工作流中的重要基础设施。
- **为什么有价值**：上下文管理是 Agent 有效性的核心，ctx 解决了一个普遍痛点，对理解 Agent 记忆和检索有重要价值，且 Rust 实现保证了性能。
- **与你的关系**：当下可直接安装和使用 ctx 检索你的历史代理会话，加快你的开发；未来可研究其索引设计，为产品中的记忆与检索功能提供参考。
- **建议动作**：安装 ctx，并针对你最近一个代理会话执行一个搜索查询，查看返回结果的效率提升。
- **Star 原因假设**：解决真实痛点且效率提升显著，受到开发者青睐；与 Agent 生态契合，作为基础设施工具获得关注；Star 增长平稳，可能依赖口碑传播
- **风险/限制**：仅支持 macOS 和 Linux 原生，Windows 用户需构建；缺少 usage 文档和测试，可能影响采用；索引本地数据可能有隐私考量，但设计上保持本地
- **判断置信度**：高
