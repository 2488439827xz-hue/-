### 4. hieuphung97/dely · 63.0/100
https://github.com/hieuphung97/dely

- **一句话**：一个多环境控制协议，将请求转换为经批准的设计合同，编排隔离的 worker 会话进行顺序实现与独立代码审查，支持 Claude Code、Codex、Cursor 等。依赖 Orca 作为执行环境。
- **解决的问题**：编码 Agent 直接执行不明确的需求，可能错误实现。传统解决方案：人工审查，但效率低。存在“信任问题”，需要协议在变更前获得设计批准。
- **独特之处**：通过合同（contract）机制强制在变更前聚焦设计，并隔离 worker 进行审查，减少确认偏差。是可复制的编排模式，适合大型项目中的可靠 Agent 交付。
- **为什么有价值**：展示 Agent 工作流如何引入人工控制关卡，对 PM 学习产品中的质量控制、用户信任设计有借鉴意义。理解“合同”与“隔离审查”可启发用户如何给 Agent 设定约束。
- **与你的关系**：
当下用途：快速了解其快速开始，理解控制协议思想，无需安装。可对照自己现有的编码 Agent 流程，思考缺什么控制。
未来用途：当团队希望提升编码 Agent 交付质量时，可引入 dely 模式。
- **建议动作**：30 分钟阅读 README 的 Design Contract 部分并撰写一页总结，反思 Agent 自动化流程中的两个关键人工关卡。
