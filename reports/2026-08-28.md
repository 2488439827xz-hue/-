## 今日项目

### 1. NVIDIA/SkillSpector · 86.0/100
https://github.com/NVIDIA/SkillSpector

- **一句话**：NVIDIA 推出的 Agent Skills 安全扫描器，可检测提示注入、数据外泄等 71 种漏洞模式，支持多格式输入与 SARIF 报告，部分集成于 NVIDIA Verified Skills 流程。
- **解决的问题**：Agent Skills 隐式信任高风险，26.1% 存在漏洞，5.2% 有恶意意图，缺乏安装前检查工具。
- **独特之处**：首个由大厂背书的开源技能安全扫描器，结合静态分析与 LLM 语义评估，提供 0-100 风险评分。
- **为什么有价值**：安全是 Agent 采用的关键障碍，SkillSpector 提供了可操作的检测方案，对个人与团队均具实际价值。
- **与你的关系**：当下：可安装并扫描常用技能，快速提升安全意识。未来：作为学习 Agent 安全设计模式的参考案例。
- **建议动作**：阅读文档并运行 `pip install skillspector`，扫描一个技能仓库并查看 JSON 报告。
- **Star 原因假设**：NVIDIA 品牌背书增强信任；Agent 安全话题热度高，痛点真实；开源且集成度高，易于试用
- **风险/限制**：扫描可能漏报，不可完全依赖；LLM 评估阶段可能引入额外成本与延迟；项目仍处早期，功能可能有变动
- **判断置信度**：High

## 今日重点

重点项目：NVIDIA/SkillSpector。目标用户：Agent 开发者、平台团队、安全工程师，以及任何需要安装第三方 Skills 的 AI 产品经理。待办任务：在安装任何 Agent Skill 前扫描其源码，识别漏洞（提示注入、数据外泄等），并生成风险评分与报告。旧替代方案：人工审查 SKILL.md 和代码，或完全信任来源，效率低且高风险。价值主张：提供自动化、可扩展的安全检查，覆盖 71 种漏洞模式，集成到 CI/CD 或 Agent 会话中，显著降低供应链风险。AI 是否必要：是。静态分析可部分自动化，但语义漏洞（如反拒绝、篡改）需要 LLM 理解上下文，AI 提供人类无法比拟的覆盖率与速度。核心指标：检测准确率（假阳性/假阴性）、扫描时间、用户采纳率（安装量、集成次数）、覆盖的漏洞类别数。主要风险：漏报导致虚假安全感；LLM 误报影响效率；依赖外部服务（OSV.dev）可用性；项目仍早期，维护与 API 稳定性风险。作品集衍生想法：撰写一篇《Agent Skill 安全风险评估报告》，选取热门技能，使用 SkillSpector 扫描，对比人工审查结果，提出改进建议，展示你如何将安全工具应用于产品决策。
